Sistema de Archivos y Registros

← Volver al índice

1. Manejo de Archivos

// Abrir archivo
abrir nombre_archivo

// Cerrar archivo
cerrar nombre_archivo

// Leer registro
leer # nombre_archivo variable1 variable2

// Escribir registro
guardar # nombre_archivo variable1 variable2

// Leer registro con posición
leer # nombre_archivo variable1 variable2 , expresion , numero

2. Definición de Registros

registro nombre_registro "nombre_archivo"
    campo1 tipo longitud
    campo2 tipo longitud
fin-registro

3. Operaciones con Registros

// Buscar registro
buscar registro nombre_registro clave

// Actualizar registro
actualizar registro nombre_registro clave

// Eliminar registro
eliminar clave

4. Sistema de Índices

// Usar índice
use índice nombre_archivo

// Cerrar índice
close índice

// Operaciones con índice
buscar clave
insertar clave
eliminar clave
actualizar clave

5. Ejemplo Completo

// Definir registro
registro clientes "clientes.dbf"
    nombre alfa 50
    edad num 3
    ciudad alfa 30
fin-registro

// Manejar archivo
abrir clientes
leer # clientes nombre edad ciudad

// Operaciones con índice
use índice clientes
buscar "Juan Perez"
actualizar registro clientes "Juan Perez"

// Cerrar todo
close índice
cerrar clientes
