1. Archivos del Programa Principal

cppapp.exe

Este es el ejecutable principal generado por la compilación.

2. DLLs de GTK+ 2.0

C:\GTK\bin\gtk-win32-2.0.dll
C:\GTK\bin\gdk-win32-2.0.dll
C:\GTK\bin\atk-1.0.dll
C:\GTK\bin\gio-2.0.dll
C:\GTK\bin\pangowin32-1.0.dll
C:\GTK\bin\pangocairo-1.0.dll
C:\GTK\bin\gdk_pixbuf-2.0.dll
C:\GTK\bin\pango-1.0.dll
C:\GTK\bin\cairo.dll
C:\GTK\bin\fontconfig.dll
C:\GTK\bin\freetype.dll
C:\GTK\bin\png14.dll
C:\GTK\bin\zlib1.dll
C:\GTK\bin\gobject-2.0.dll
C:\GTK\bin\gmodule-2.0.dll
C:\GTK\bin\gthread-2.0.dll
C:\GTK\bin\glib-2.0.dll
C:\GTK\bin\intl.dll

Todas estas DLLs son necesarias para el funcionamiento de la interfaz gráfica GTK+. En tu sistema, las DLLs deberían estar en:

  • C:\GTK\bin\ - DLLs principales (ya está en tu PATH)
  • C:\Program Files (x86)\GtkSharp\2.12\bin\ - Otra instalación posible
  • c:\gtk\bin\ - Otra posible ubicación

Alternativamente, si no las encuentras en estas ubicaciones, puedes:

  1. Instalar GTK+ 2.0 Runtime desde el sitio web oficial
  2. O copiar las DLLs necesarias a la carpeta donde está tu ejecutable cppapp.exe

Nota: Si instalas GTK+ 2.0 Runtime, asegúrate de que las nuevas DLLs se añadan correctamente a tu PATH.

3. Archivos de Configuración GTK+

themes
etc
share

Estos directorios contienen los archivos de configuración necesarios para GTK+.

4. DLL de BTree

btree.dll

Esta DLL es necesaria para el manejo de índices y estructuras de datos.

5. Archivos de Ejemplo

ARCHIVOS.PR
CONTACTS.CSV
LISTADO.PR
contacts.dbf
contacts.ndx

Estos archivos son necesarios para los ejemplos y pruebas del programa.

6. Estructura de Carpetas Recomendada

Carpetas Contenido
bin/ cppapp.exe, todas las DLLs de GTK+, btree.dll
data/ Archivos de ejemplo (.PR, .CSV, .DBF, .NDX)
lib/ Archivos de configuración GTK+ (themes, etc, share)

7. Pasos para Preparar la Instalación

  1. Copiar cppapp.exe a la carpeta bin/
  2. Copiar todas las DLLs de GTK+ a bin/
  3. Copiar btree.dll a bin/
  4. Copiar archivos de ejemplo a data/
  5. Copiar archivos de configuración GTK+ a lib/
  6. Configurar las variables de entorno GTK2_RC_FILES y GTK_PATH

8. Variables de Entorno Necesarias

Variable Valor Descripción
GTK2_RC_FILES lib/etc/gtk-2.0/gtkrc Archivo de configuración GTK+
GTK_PATH lib Ruta de los archivos de configuración GTK+
