Árbol de Sintaxis Abstracta (AST)

1. Implementación Actual

struct ast {
    tiponodo tipo;
    double num;
    int    nrolinea1;
    int    nrolinea2;
    int subnodos;
    struct ast * nodo1;
    struct ast * nodo2;
    struct ast * nodo3;
    struct ast * nodo4;
    struct ast * nodo5;
};

Aspectos Positivos

  • Simplicidad y claridad en la estructura básica
  • Tipos de nodos bien definidos y organizados
  • Flexibilidad para manejar diferentes tipos de operaciones
  • Manejo de memoria con funciones específicas
  • Sistema de pila para programas y registros

Aspectos que Mejorarían

  • Punteros a subnodos hardcodeados y limitados a 5
  • Solo maneja double para valores numéricos
  • Gestión de memoria dispersa
  • Tipos mezclados en el enum
  • Manejo de errores disperso

2. Propuesta de Mejora

// Definición moderna del AST
typedef enum {
    TYPE_NUMBER,
    TYPE_STRING,
    TYPE_BOOLEAN,
    TYPE_NULL,
    TYPE_ARRAY,
    TYPE_OBJECT
} ValueType;

typedef enum {
    NODE_TYPE_LITERAL,
    NODE_TYPE_BINARY,
    NODE_TYPE_UNARY,
    NODE_TYPE_ASSIGN,
    NODE_TYPE_VAR_DECL,
    NODE_TYPE_IF,
    NODE_TYPE_WHILE,
    NODE_TYPE_FUNCTION,
    NODE_TYPE_CALL,
    // ... más tipos
} NodeType;

struct ast_node {
    NodeType type;
    ValueType value_type;
    union {
        double number;
        char *string;
        int boolean;
        struct {
            struct ast_node *left;
            struct ast_node *right;
        } binary;
        struct {
            struct ast_node *operand;
        } unary;
        struct {
            struct ast_node *target;
            struct ast_node *value;
        } assign;
        // ... más uniones
    } value;
    struct ast_node **children;  // Array dinámico
    size_t num_children;
    int line_number;
    int column_number;
    struct {
        bool is_constant;
        bool is_mutable;
        // ... más flags
    } flags;
};

Mejoras Propuestas

  • Tipos de datos más robustos
  • Número variable de hijos
  • Mejor separación de responsabilidades
  • Sistema de tipos más completo
  • Mejor manejo de memoria
  • Sistema de errores más robusto

4. Consideraciones Finales

La implementación actual es funcional pero tiene limitaciones que la hacen menos escalable y mantenible. La propuesta mejorada busca abordar estos problemas manteniendo la simplicidad mientras se agrega flexibilidad y robustez al sistema.
