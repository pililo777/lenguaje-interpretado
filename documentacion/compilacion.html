Compilación del Proyecto

← Volver al índice

1. Requisitos Previos

- Cygwin con GCC
- GTK+ 2.0 para Windows
- Flex y Bison
- Ruta de las librerías GTK+ configurada

2. Archivos Generados

1. lex.yy.c - Generado a partir de tokens.l usando Flex
2. grammar.tab.c - Generado a partir de grammar.y usando Bison

3. Pasos de Compilación

3.1 Generar archivos de lex/yacc

flex tokens.l
bison -d grammar.y

3.2 Compilar archivos .c individuales

gcc -c bt.c -o bt.o
gcc -c dbase.c -o dbase.o
gcc -c dinamic.c -o dinamic.o
gcc -c err.c -o err.o
gcc -c graficos.c -o graficos.o
gcc -c lex.yy.c -o lex.yy.o
gcc -c grammar.tab.c -o grammar.tab.o
gcc -c minieditor.c -o minieditor.o
gcc -c run.c -o run.o
gcc -c variables.c -o variables.o

3.3 Enlazar todos los archivos .o

gcc -m32 -mms-bitfields -o cppapp.exe 
    bt.o dbase.o dinamic.o err.o graficos.o 
    grammar.tab.o lex.yy.o minieditor.o run.o variables.o
    -L/cygdrive/c/gtk/lib 
    -lgtk-win32-2.0 -lgdk-win32-2.0 -latk-1.0 -lgio-2.0 
    -lpangowin32-1.0 -lgdi32 -lpangocairo-1.0 -lgdk_pixbuf-2.0 
    -lpango-1.0 -lcairo -lfontconfig -lfreetype -lpng14 -lz 
    -lgobject-2.0 -lgmodule-2.0 -lgthread-2.0 -lglib-2.0 -lintl

4. Notas Importantes

  • Se compila en modo 32 bits usando -m32
  • Se usa -mms-bitfields para compatibilidad con Windows
  • El ejecutable final se llama cppapp.exe
  • Todas las librerías GTK+ deben estar disponibles
