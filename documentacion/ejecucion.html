Sistema de Ejecución

1. Flujo de Ejecución

  1. El flujo de ejecución principal se inicia de dos formas:
    • Comando "run" en la línea de comandos del CLI
    • Botón "Ejecutar" en el mini-editor gráfico
  2. El buffer buff1 se utiliza solo temporalmente para:
    • Comandos del CLI de dBase
    • Modo "interpretar el comando como si fuera una línea de programa" (comando "inter")
  3. El flujo de ejecución completo es:
    1. Se inicia la lista de nodos con iniciarLista()
    2. Se configura el buffer de entrada
    3. Se ejecuta el parser (yyparse)
    4. Si no hay errores, se ejecuta el programa con execut()
    5. Las expresiones se evalúan con evalua()
  4. El comando run ejecuta programas de la pila de programas:
    • Comienza en el índice 0
    • Incrementa el índice para ejecutar el siguiente programa
    • No borra las variables entre ejecuciones

2. Manejo de Errores

  • Variable global err_number para errores
  • Sistema de backup de programas
  • Restauración de estado tras errores
  • Manejo de errores en tiempo de ejecución

3. Sistema de Pila

  • Pila de programas (32 programas máx.)
  • Pila de registros (32 registros máx.)
  • Manejo de memoria para cada nivel
  • Restauración de estado

4. Funciones Principales

// Función principal de ejecución
void execut(ast * p)
{
    switch (p->tipo) {
        case suma: 
            // ... ejecuta operación de suma
            break;
        case resta:
            // ... ejecuta operación de resta
            break;
        // ... más casos
    }
}

// Evaluación de expresiones
double evalua(ast * p)
{
    switch (p->tipo) {
        case NUMBER:
            return p->num;
        case VARIABLE:
            return obtener_valor_variable(p->nodo1);
        // ... más casos
    }
}
