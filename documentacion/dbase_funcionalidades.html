Funcionalidades de dbase.c

1. CLI (Command Line Interface)

  • Prompt interactivo con 44 comandos disponibles
  • Sistema de parsing de comandos
  • Manejo de errores y ayuda
  • Modo interactivo

2. Sistema de Programas

  • Carga de programas en lenguaje propio
  • Creación de AST (Árbol de Sintaxis Abstracta)
  • Ejecución de programas cargados
  • Pila de programas (32 programas máx.)

3. Sistema de Variables

  • Variables numéricas y alfanuméricas
  • Arrays multidimensionales
  • Visualización de variables en formato JSON
  • Sistema de memoria para variables

4. Sistema de Depuración

  • Breakpoints (hasta 20)
  • Depuración remota por sockets
  • Control de ejecución paso a paso
  • Visualización de estado

5. Interfaz Gráfica

  • Integración con GTK
  • Soporte para GUI
  • Editor integrado

6. Sistema de Archivos

  • Manejo de archivos
  • Sistema de buffers
  • Carga y guardado de programas

7. Sistema de Memoria

  • Gestión de memoria para variables
  • Sistema de constantes
  • Manejo de buffers

8. Sistema de Networking

  • Servidor socket en puerto 8080
  • Comunicación remota
  • Depuración remota

9. Sistema de Índices

  • Búsqueda rápida
  • Insertar y eliminar elementos
  • Sistema de claves
